# AGENTS.md

Instructions and context for AI coding assistance in this repository:

1. **Language & Environment**: Use Python 3 exclusively. Do not introduce other programming languages, web frameworks, external databases, or unnecessary third-party libraries.
2. **Simplicity & Readability**: Keep the application beginner-friendly, modular, readable, and easy to explain in an academic laboratory viva. Avoid unnecessary abstractions or complex design patterns.
3. **Coding Standards**: Adhere to PEP 8 standards using Ruff for linting and formatting. Ensure meaningful variable names, single-responsibility functions, and descriptive docstrings.
4. **Testing**: Write or update Pytest tests whenever functionality or business logic changes. Ensure test cases cover normal execution, boundary values, and error scenarios.
5. **No Unnecessary Dependencies**: Use Python's standard library. Only `pytest` and `ruff` are used as development tools.
6. **Security & Secrets**: Never hardcode sensitive data, passwords, API keys, or local absolute paths into the codebase.
7. **Explanations & Transparency**: Explain significant code changes in simple, clear language so the student can easily understand and defend the implementation during examination.
8. **Git Safety**: Do not run Git commands, create commits, or push to remotes without explicit user confirmation.
